# QA Documentation

This folder contains the initial QA, integration, and demo-preparation notes for the Insurance Policy Generation Chatbot repository.

The documents are intended to help another person understand what has been verified, what is still pending, and how to run the currently available checks without changing the RAG logic or API contracts.

## Documents

- [QA checklist](qa_checklist.md): verification checklist for environment, API, Git hygiene, integration, sources, Qdrant, retrieval, and demo readiness.
- [API manual test cases](api_manual_test_cases.md): Swagger-oriented manual test cases for `/health`, `/config`, and `/ask`.
- [Test execution log](test_execution_log.md): recorded test execution evidence and observations.
- [Integration status](integration_status.md): current implementation status for available and pending integration pieces.
- [Demo runbook](demo_runbook.md): existing repository commands for local setup, tests, and API startup.
- [Known issues](known_issues.md): current risks and non-blocking issues to monitor.
